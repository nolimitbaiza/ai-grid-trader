Buy low, sell high

The agent charges in the overnight lull and the midday solar dip, then sells into the morning and evening peaks.

02

Every cycle has a price

Each MWh through the battery carries a wear cost. Trades that don't beat it are skipped, so the asset lasts longer.

03

Decisive, not twitchy

Starting a new charge or discharge run has a cost, so the agent commits to a few clean cycles instead of chasing every price wiggle.

How the agent decides

Every 15 minutes the agent picks how much to charge, discharge or hold. Its reward is:

reward = arbitrage cash − battery wear − micro-cycling penalty

The state is the time, the battery's charge level and whether it is currently charging, discharging or holding. The agent's decision table is computed with exact Bellman updates, which give the same answer a fully trained Q-learning agent converges to, in milliseconds and with identical results every time.
